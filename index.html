노션 입출고 → 세금계산서 DB → 홈택스 엑셀양식 · 단계별 대사

연결 대기
0

원본 스냅샷 기준치 확정

입출고 DB에서 이 집계월의 페이지·고유 거래처·박스·금액을 고정합니다. 이후 모든 단계는 이 숫자와 대사됩니다.

1

노션 세금계산서 DB 자동화 수창 사고 지점

입출고 페이지 → 세금계산서 DB 페이지 생성 + 3개 체크박스(계산서발행·처리중·발행완료) 상태를 숫자로 검증합니다.

2

홈택스 엑셀양식 자동화 거래처 취합·합산

동일 거래처 1행 취합 + 수량·금액 합산. 입력 합계 = 집계 합계 + 사업자번호없음 합계를 강제 대사합니다.

E

예외 처리 삭제·수정

이번 달 발행에서 빼거나 수량·금액을 바꿀 건을 등록합니다. 3단계에서 자동 반영되고 "월별 이슈사항" 시트에도 기록됩니다.

3

최종 확정 · 단계별 대사 발행 직전 게이트

원본 → 연동 → 사업자번호없음 → 예외 → 최종 행. 설명불명 차액이 0일 때만 파일 확정이 가능합니다.
